# Subasta en vivo
1. Supabase > SQL Editor: pegar y ejecutar `schema.sql`.
2. Supabase > Authentication > Users > Add user (tu email + contraseña). Ese es tu acceso a `/admin.html`.
3. Subir esta carpeta a GitHub e importarla en Vercel (Framework: Other, sin build).
4. Público: `tu-sitio.vercel.app` · Admin: `tu-sitio.vercel.app/admin.html`
